# AI Response Evaluation Sample

A small, **synthetic portfolio exercise** showing a repeatable way to review AI-generated answers for quality. All prompts and responses below are fictional examples created for demonstration; they do not represent client work or production data.

## Review rubric

Score each dimension from 1 (poor) to 5 (strong), and include a short evidence-based note.

| Dimension | What to check |
|---|---|
| Relevance | Does the answer address the user's actual question? |
| Factual support | Are claims supported by the prompt or reliable evidence? |
| Completeness | Does it cover the key requested points without important gaps? |
| Clarity | Is it direct, readable, and well organized? |
| Safety | Does it avoid harmful, private, or overconfident guidance? |
| Instruction following | Does it respect the requested format and constraints? |

## Synthetic example

**Prompt:** “How can I keep a houseplant alive while I am away for a week?”

**Candidate response:** “Water it heavily every day before leaving. Put it in direct sun so it grows faster.”

**Review:** Relevance 3/5 · Factual support 1/5 · Completeness 2/5 · Clarity 3/5 · Safety 3/5 · Instruction following 3/5

**Rationale:** It offers relevant actions but gives overly broad advice. Daily watering and direct sun may harm some plants. A stronger answer would advise checking the plant's needs, watering appropriately before leaving, and placing it in suitable light.

## Quality workflow

1. Read the user request and identify required facts and constraints.
2. Check each response against the same rubric.
3. Record the exact evidence behind each rating.
4. Flag unsupported claims, omissions, ambiguity, and safety concerns.
5. Re-review borderline cases and keep the final rationale concise.

## Limits

This is an illustrative sample, not a benchmark or claim of measured model performance. Scores are demonstration judgments and should be calibrated with task-specific guidelines before operational use.
